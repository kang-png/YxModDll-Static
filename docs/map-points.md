# 本局公共点与坐标传送

F10 大地图显示原版存档、自定义存档和公共 warp；★ 表示当前存档。

文字和按钮沿用 UI 的菜单颜色、渐变与文字格式；点位图标保留分类颜色。每次打开 F10 时路径点侧栏默认收起，点击下方“路径点”展开。

- 右侧列表点击定位、右键操作；地图上的标记也支持右键。
- 右键地面可以创建点、复制落点坐标或传送过去。选中的地面上方 1 米作为人物落点；洞穴和多层地图按地图当前视角实际命中的地面取点。
- 房主可以在自己当前位置创建点。名称留空时自动分配不重名的 `warp1`、`warp2` 或 `存档点1`、`存档点2`，创建后清空名称输入框，也可改名或删除。
- 自定义存档带半径 1.5 米的触发范围，任意玩家进入后更新全员当前存档；普通行走不会激活已经经过的较早自定义点，房主可手动激活旧点。
- 关闭原版存档后，自定义存档仍能触发。重生沿用原版人物重置和从空中落下的流程；机关、物体的重置沿用激活时的原版关卡进度，不保存任意场景快照。
- warp 是随时可返回的公共位置，创建和使用 warp 不主动更新存档；传送期间屏蔽人物经过的普通检查点和自定义点，避免途中误触。
- 创建、改名、删除和手动激活仅房主可用。传送遵守现有传送系统开关；客机使用自己的传送需要聊天框权限，控制他人另外检查客机权限和目标保护。
- 所有新增点仅本局有效：重新开始整局、换图或离开房间时清空；普通重生、重载当前存档保留。
- 支持该功能的 YxMod 客机自动同步公共点；原版客机可以向房主发送普通聊天命令使用 warp 和坐标传送。

| 命令（可以加 `/` 前缀） | 用途 |
| --- | --- |
| `pos` | 查看自己的 X Y Z 坐标，Y 为高度 |
| `tppos 100 25 -30` | 将自己传送到坐标，支持负数和小数 |
| `tppos ~ ~5 ~-2` | 相对当前位置上移 5 米、Z 减少 2 米 |
| `tppos 3 100 25 -30` | 将当前玩家列表中的 3 号玩家传送到坐标 |
| `setwarp 桥头` / `setwarp` | 房主在当前位置创建公共 warp，省略名称自动编号 |
| `warp 桥头` | 传送到公共 warp |
| `warps` | 列出本局所有公共 warp |
| `delwarp 桥头` | 房主删除公共 warp |

F10 右侧也提供当前坐标复制、坐标输入和传送，无需输入聊天命令。已有的个人定点和读点不受影响。

验证：`tools/x64/test-map-points.ps1` 在隔离的 Unity 副本验证物理触发、实际 Game.Respawn、坐标输入、权限、同步数据和 F10 IMGUI；加 `-Protected` 验证打包后的 Release DLL。
