YxMod x64 / Unity 2017.4.13f1

安装：退出游戏，双击 YxMod-x64-Setup.exe，自动定位 Steam 游戏并安装。
安装时强制联网检查最新版本，不受启动更新的6小时间隔限制。
已有旧 Mod 会被校验后的在线新版替换；配套组件变化时自动下载新版安装器继续安装。
旧安装器也会获取新版，先交接新版安装器，再安装对应的整套文件。
联网失败时明确提示未确认在线最新版，使用内置文件安装；有更新记录可验证的较新版则保留。
ZIP 安装：将全部文件解压至 Human.exe 所在目录并替换，不能多套一层文件夹。
Human.exe 与安装器使用 Steam 原版人类图标；标题栏、任务栏和自动恢复后的图标保持一致。
日常使用：从 Steam 正常开始游戏，不需要修改启动选项。

游戏验证或重新下载后，只要修复入口仍保留：
winhttp.dll 会在 UnityMain 前拦截启动；YxMod-x64.exe 等待游戏退出，
恢复64位文件，并提示再次从 Steam 启动。
完整删除游戏目录也会删除修复入口，此时需要重新运行安装器。
安装和修复不绑定游戏版本号或 Assembly-CSharp.dll 哈希，不替换该主程序集。

文件说明：
winhttp.dll：自动恢复入口；YXWIN64.dll：定制 Doorstop。
64位 UnityPlayer.dll 使用 YXWIN64.dll，系统 WinHTTP API 由加载器正确转发。
YxModDll-x64.dll：独立的64位更新渠道（托管程序集保留 AnyCPU）。
.yxmod-x64/assets/<内容哈希>/YxModAssets-x64.dll：离线 emoji 图集资源，保留其完整目录。
YxMod-x64.exe：与同次发布的安装器为相同程序，负责安装、自动恢复和启动前更新，需留在游戏目录。
日常自动修复保留已有的 YxModDll-x64.dll；双击安装则主动检查更新并替换旧版。

更新：OSS x64 目录优先，GitHub Static x64 目录备用，成功检查后间隔6小时。
检查超过半秒时显示更新窗口，提供百分比、已下载/总大小及实时速度；完成后自动继续启动。
1 MB 及以上的更新文件使用4路分段下载；服务器不支持分段时使用单连接。
下载持续有数据时不再因超过90秒被强制终止；连接或读取停滞仍会超时并切换备用源。
启动更新窗口可点击“跳过本次更新”（或关闭窗口），停止下载后使用已有 Mod 继续启动。
在 Human.exe 同级放置 skip_update.flag 可跳过联网更新，删除后恢复。
该标记也适用于双击安装：仅安装/修复内置环境，保留已有 Mod。
该标记不影响运行环境自动恢复，也不影响缺少 Mod DLL 时从安装资源离线补齐。
仅接收 channel=x64、正确文件名、完整提交版本、大小及 SHA-256 均匹配的更新。
启动更新时源故障/校验失败保留当前 DLL，错误写入 .yxmod-x64/bootstrap.log。
只有 Mod 变化时只下载 YxModDll-x64.dll，不下载 EXE。
emoji PNG 已从 Mod DLL 拆出，按内容 SHA-256 单独缓存；代码更新不重复下载相同图集。
缺失或损坏的 emoji 资源由游戏后台直接从 OSS/GitHub/镜像补齐，不等待更新器、不要求重启。
下载中保留 Unicode 原文；图片暂时透明，校验完成后自动显示。已缓存资源断网可用。
skip_update.flag 禁用更新清单检查，但不阻止游戏补齐缺失的固定 emoji 素材。
更新清单支持通用文件条目：runtime 游戏内下载，startup 启动前安装；新增普通资源不必重写更新器。
EXE 和 ZIP 含完整离线资源，断网可安装/修复；首次迁移到分离资源机制可能需要更新安装器一次。
firstpass、原生加载器或运行环境变化时，下载并校验新版安装器。
更新器有独立的 updater 版本：仅更新器变化时，由原生入口等待旧 EXE 退出，
运行已校验的暂存新版替换自身，并继续本次更新和游戏启动，不要求重启游戏。
运行环境/加载器的 components 版本独立计算，不因单独修改更新器或 Mod 而变化。
游戏退出、解除文件占用后，由该 EXE 安装整套配套组件，完成后提示重新从 Steam 启动。
组件版本独立于 Mod、构建时间和 EXE 内嵌的 Mod，不因单独发布 Mod 而反复下载 EXE。
完全无法更新 Mod 的早期版本需手动安装一次；能更新 Mod 的旧版可通过下面的反向通道迁移。
新 Mod 另有反向升级通道：进游戏8秒后异步检查更新器，后台下载、校验新版安装器，
不依赖旧更新器认识组件升级协议。只要旧版能更新到这个 Mod，就能尝试自动迁移。
游戏运行时，旧更新器 EXE 已退出，可直接替换；UnityPlayer/YXWIN64 等已加载文件不替换。
新版安装器在后台等待这次游戏退出，再安装配套组件；等待期间不占用启动更新锁。
skip_update.flag 同样禁用 Mod 的反向升级通道。新版清单缺少 updater 字段时不启动此通道。
旧版首次下载 Mod 仍使用旧代码；完全不能更新 Mod 的旧版仍需手动安装一次。

卸载：退出游戏，删除本包 winhttp.dll、YXWIN64.dll、YxMod-x64.exe、
YxModDll-x64.dll，再用 Steam 验证游戏文件，防止自动修复再次生效。
不包含账号、存档、个人配置或自动建房探针。
